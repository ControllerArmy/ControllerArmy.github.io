About

Where code meets the road.

I am a Computer Science student at Gonzaga University, Class of 2030. On Gonzaga Baja SAE I'm building a telemetry system for our competition vehicle, and my first-year design project, PATHFINDER, was firmware for a handheld sensor tool that had to run lean on a constrained platform. Before college I led programming on two shipped Unity games at DigiPen Academy. I'm working toward a career in video games, and I'd also love to write software for an electric vehicle company, because I want my code to help make transportation cleaner. Away from the keyboard I play for Gonzaga Men's Lacrosse, photograph cars, and chase lap times in sim racing.
